# Security policy

## Supported versions

Security fixes are developed on the active `0.1.x` line until a supported
release policy is published.

## Reporting a vulnerability

Do not disclose vulnerabilities through public issues. Contact the repository
owner privately with a reproducible description, affected versions, impact,
and any proof of concept that does not contain production data or credentials.

Clarus must never be used to bypass GLPI Ticket authorization or to execute
Ticket business-rule actions during inspection.
